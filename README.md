# lawchunk-rl

한국어 법령 RAG에서 **청크 구조(청킹)를 강화학습으로 학습**해 보는 실험 프로젝트.

> **면책:** 이 저장소는 연구/실험 목적입니다. 어떤 출력도 **법률 자문이 아니며**, 법적 판단의 근거로 사용할 수 없습니다.

## 아이디어

- 법령은 조>항>호 계층과 상호 참조("제3조제2항")가 뚜렷해서, 청킹이 구조를 따르느냐에 따라 검색 성능(Recall@k, MRR)이 달라진다.
- 이 차이를 먼저 베이스라인으로 측정하고, 이후 보상(검색 성능 − 청크 수/길이 페널티)으로 청킹 정책을 학습한다.

## 현황

- [x] 수집(`fetch.py`), 조/항/호 파싱 + 내부 참조 추출(`parse.py`)
- [x] 청킹 베이스라인: 고정 길이 / 조 단위 / 조+항 계층형, 맥락 접두어 옵션(`chunk.py`)
- [x] 평가 파이프라인(`embed.py`, `evaluate.py`, `gen_questions.py`): bge-m3 고정, 조문 단위 Recall@k / MRR
- [x] 베이스라인 비교(근로기준법, 민법): 구조를 따르는 청킹이 고정 길이보다 크게 우수. 참조 조문 결합(`article+refs`)은 참조가 있는 조문에서만 이득
- [ ] 조문별 bandit(참조 결합 on/off) → 문장 경계 cut/merge 정책
- [ ] 실제 질문(법령해석 사례, 생활법령 Q&A) 기반 고정 평가셋

## 사용

국가법령정보센터 Open API 인증키(OC)가 필요합니다. 저장소 루트에 `.env`를 만들고 `LAW_OC=...`를 넣으세요. (`.env`와 `data/`는 커밋되지 않습니다.)

```bash
export PYTHONPATH=src
python3 -m lawchunk.fetch 근로기준법
python3 -c "from lawchunk.parse import main; main('근로기준법')"
python3 -m lawchunk.chunk 근로기준법
```

## 데이터

법령 원문은 재배포 조건을 확인하지 못해 저장소에 포함하지 않습니다. 수집 스크립트로 직접 내려받으세요. 법령은 시행일마다 버전이 다르므로 한 시점으로 고정해 사용합니다.
